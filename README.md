# Currency Converter
#### Video Demo: https://youtu.be/E9roJLsLN9k
#### Description:
A python script that gets the latest exchange rate of multiple currencies and stores said values in a database for future and offline use.
 I used a sqlite database in order to still have access to relatively recent rates without a network connection
The convert section of the project allows user to chose custom amounts to convert between a primary currency of their choice and a secondary currency.I used sqlite because it is built into python and is easy(relatively) to implement in programs

#### How the project works
The project is split across three files: project.py, convert.py, and test_project.py. project.py handles everything to do with getting and storing exchange rate data. network_check() pings google.com to see whether the user actually has an internet connection before trying to hit the currency API, since there's no point trying to fetch fresh rates if there's no connection anyway. If there is a connection, update_db() grabs the latest USD-based exchange rates from the currency-api hosted on jsdelivr, and either creates a fresh rates.db SQLite database or, if one already exists, updates the existing rows using an upsert (INSERT ... ON CONFLICT DO UPDATE) so old rates get overwritten instead of duplicated. If there's no connection at all, print_stored_data() kicks in instead and just reads whatever was last saved to the database, so the user still gets something useful even offline, as long as they've run the program online at least once before to create a cache so tosay

convert.py is the part that a user can interact with the most. It runs the network_check and update logic from project.py first, then asks the user for an amount along with a primary and secondary currency. It looks both currencies up in the database, and if either one isn't found it tells the user instead of crashing. The actual conversion math routes everything through USD first (since that's what the API rates are all based on), dividing by the primary currency's rate and multiplying by the secondary's, before printing the converted amount nicely formatted with commas and two decimal places.
